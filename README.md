# Ashen Oath

A Windows-first, 2D grimdark pixel-art Match-3 roguelite in Godot 4 / GDScript.

**Status:** Foundation only. The project opens on a placeholder title screen; combat and inventory are not yet implemented.

## Quick start
1. Install Godot 4 (standard edition).
2. Extract the ZIP into `C:\dev` (it contains the `ashen-oath` folder).
3. Open Godot Project Manager → Import → select `project.godot`.
4. Run project with F6/F5 (F5 runs main scene).
5. For Codex CLI, open a terminal in the repository and run `codex`, then sign in with ChatGPT.

## Guidelines
- Make one small, playable vertical slice before expanding content.
- Commit working milestones with Git.
- Art assets must be licensed or generated for this project and reviewed for consistency.
- Keep UI text and repository documentation in English; conversations may be in Ukrainian.

## Current prototype
